## ⭐ Featured Research

### Nepali Devanagari OCR

An end-to-end system for recognizing printed and handwritten Nepali Devanagari text.

**Research highlights**
- Compared CNN-BiLSTM-CTC (CRNN) and Transformer-based TrOCR approaches
- Trained CRNN on **92,000 character images across 46 classes**
- Achieved **98.67% character-level accuracy**
- Fine-tuned TrOCR on **4,358 labeled handwritten Nepali word images**
- Evaluated word recognition using **CER, WER, and exact-match metrics**
- Investigated challenges involving limited labeled data, handwriting variation, Devanagari character composition, and model-domain mismatch
- Built an end-to-end **FastAPI + React** OCR application for images and PDFs

**Research direction:** data-efficient document understanding and multimodal learning for low-resource languages and scripts.
